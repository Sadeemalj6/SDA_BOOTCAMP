# Computer Vision Bootcamp - Day 1

My first hands-on Computer Vision lab as part of the **Computer Vision Bootcamp** by **Saudi Digital Academy (SDA)**.

## Lab Overview

In this lab, I built a mini Computer Vision pipeline and applied different image processing techniques to an image.

### What I Learned

* Loading and displaying images
* Converting images to grayscale
* Edge detection
* Image preprocessing
* Image augmentation
* CNN preview for object recognition

### Pipeline

`Load Image → Grayscale → Edges → Preprocess → Augment → CNN Preview`

### Tools & Libraries

* Python
* OpenCV
* NumPy
* Matplotlib
* Jupyter Notebook
